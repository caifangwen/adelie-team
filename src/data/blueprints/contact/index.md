# 免费诊断 / 联系我们

## 01. Hero
- 眉题：`START A CONVERSATION`
- 标题：`先聊清楚问题，再讨论要做什么。`
- 正文：`留下网站、商店或广告账户的基本情况。我们会先判断最值得优先处理的机会，以及双方是否适合合作。`
- 组件：`SiteHeader`、`ContactHero`。

## 02. 咨询表单
- 标题：`告诉我们你的现状。`
- 必填字段：`姓名`、`公司/品牌`、`工作邮箱`、`网站或商店链接`、`希望解决的问题`。
- 选填字段：`目标市场`、`感兴趣的服务`（WordPress / Shopify / SEO / Google Ads / 整站增长）、`预计启动时间`、`预算范围`。
- 提交按钮：`提交诊断申请`。
- 隐私说明：`我们只会使用这些信息回复你的咨询，不会出售或公开你的资料。`
- 组件：`QualifiedLeadForm`、`InputField`、`SelectField`、`TextareaField`、`ConsentCheckbox`、`SubmitButton`。

## 03. 提交后状态
- 成功标题：`已收到，我们会尽快回复。`
- 成功正文：`通常会在 1–2 个工作日内回复。如果项目紧急，请通过商务邮箱联系。`
- 表单错误：`请填写工作邮箱和网站链接，方便我们完成初步判断。`
- 组件：`SuccessMessage`、`InlineValidation`、`ErrorSummary`。

## 04. 其他联系方式
- 商务邮箱：`hello@yourdomain.com`（上线前替换）。
- 工作时间：`周一至周五 09:00–18:00（中国标准时间）`（按团队实际时间替换）。
- 社媒/即时通讯：只放置实际维护的渠道。
- 组件：`ContactMethodList`、`SocialLinkList`。

## 05. 合作预期
- `初步诊断包含什么？`：`对网站、页面、SEO 或账户提出高优先级观察，不替代完整审计。`
- `一定要合作吗？`：`不需要；先判断是否匹配。`
- 组件：`ExpectationList`、`Accordion`、`SiteFooter`。

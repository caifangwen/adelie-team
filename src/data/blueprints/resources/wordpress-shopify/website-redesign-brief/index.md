# 文章详情：网站改版前，怎样收集内容才不会拖慢上线？

## 01. Article Header
- 图片：`https://images.unsplash.com/photo-1498050108023-c5249f4df085`
- 分类：`建站准备`；阅读时长：`6 分钟`。
- 标题：`网站改版前，怎样收集内容才不会拖慢上线？`
- 摘要：`在设计开始前确定页面责任人、现有素材与缺口，能减少后期反复修改。`
- 组件：`SiteHeader`、`ArticleHeader`、`AuthorMeta`、`ShareActions`。

## 02. 正文清单
- `确定页面清单`：`先列出必须上线的产品、行业、服务、案例与联系页面。`
- `标记内容责任`：`每个页面明确谁提供资料、谁确认技术信息、谁最终审核。`
- `补齐证明材料`：`提前收集图片、案例、认证、规格和常见问题。`
- 组件：`ArticleBody`、`ChecklistBlock`、`ContentInventory`。

## 03. 文末 CTA
- 文案：`下载建站需求清单，把改版准备工作一次梳理清楚。`
- 组件：`DownloadCTA`、`RelatedArticleList`、`SiteFooter`。

## 02. 评分维度
- `清晰度`：`首屏能否回答“这是什么、适合谁、有什么好处”。`
- `证据`：`是否有评价、案例、数据、认证或具体说明。`
- `行动`：`CTA 是否明确，表单是否只收集必要信息。`
- 组件：`ScorecardPreview`、`ScoreRow`。

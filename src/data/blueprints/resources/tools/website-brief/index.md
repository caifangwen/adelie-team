# 下载页：建站需求清单

## 01. Hero
- 标题：`把“想做一个新网站”，变成可执行的项目需求。`
- 正文：`用这份清单整理业务目标、目标市场、页面需求、内容责任和上线标准。`
- 组件：`SiteHeader`、`DownloadHero`、`PrimaryButton`。

## 02. 清单包含什么
- `业务与受众`：`目标、市场、买家和竞争对手。`
- `页面与内容`：`必需页面、现有素材、缺失内容与审核人。`
- `功能与数据`：`表单、语言、支付、追踪、合规和维护要求。`
- 组件：`ChecklistPreview`、`ChecklistItem`。

## 03. 下载表单
- 标题：`把清单发送到邮箱。`
- 字段：`姓名`、`工作邮箱`、`公司`；勾选项：`我同意接收相关建站内容。`
- 成功提示：`已发送。请检查邮箱；如果没收到，也可以直接联系我们。`
- 组件：`EmailCaptureForm`、`ConsentCheckbox`、`SuccessMessage`、`SiteFooter`。

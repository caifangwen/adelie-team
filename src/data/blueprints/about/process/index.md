# 合作流程

## 01. Hero
- 图片：`https://images.unsplash.com/photo-1552664688-cf412ec27db2`
- 标题：`合作开始前，你应该知道每一步会发生什么。`
- 正文：`无论是建站、SEO 还是广告项目，我们都先对齐目标、范围、责任人与数据口径。`
- 按钮：`发起项目沟通`。
- 组件：`SiteHeader`、`AboutHero`、`PrimaryButton`。

## 02. 启动阶段
- 图片：`https://images.unsplash.com/photo-1521737711867-e3b97375f902`
- `沟通与诊断`：`了解市场、业务目标、既有数据和限制条件。`
- `方案与报价`：`列清交付物、优先级、时间线、双方责任与不包含事项。`
- `启动准备`：`确认素材、审批人、账号权限和沟通节奏。`
- 组件：`ProcessSteps`、`StepItem`。

## 03. 执行阶段
- 图片：`https://images.unsplash.com/photo-1522071820081-009f0129c71c`
- `先确认策略和结构`：`避免在方向未定时反复修改视觉或开发。`
- `分阶段交付`：`关键节点提供可审阅成果，并集中收集反馈。`
- `测试与上线`：`检查页面、表单、设备、追踪和关键业务流程。`
- 组件：`ProcessSteps`、`StepItem`。

## 04. 持续合作
- 图片：`https://images.unsplash.com/photo-1551836022-d5d88e9218df`
- `月度报告`：`看目标、动作、数据变化和下月优先级。`
- `季度复盘`：`看市场、页面、内容与渠道是否需要调整。`
- 组件：`Timeline`、`TimelineItem`。

## 05. FAQ + CTA
- `谁需要参与？`：`至少需要一位业务负责人和一位能确认内容的人。`
- `如何验收？`：`以项目启动时确认的页面、功能、数据与上线标准为准。`
- 组件：`Accordion`、`LeadForm`、`SiteFooter`。

# 团队与方法论

## 01. Hero
- 标题：`一支能把网站做完，也能把增长接上的团队。`
- 正文：`我们不把策略、设计、开发、SEO 与广告拆成互不理解的工序，而是围绕同一个业务目标协作。`
- 组件：`SiteHeader`、`AboutHero`。

## 02. 团队能力
- `策略`：`把模糊的业务目标转化为页面、内容和流量优先级。`
- `设计与开发`：`让复杂信息容易理解，也能被客户团队长期维护。`
- `SEO 与 SEM`：`把流量质量、转化追踪和结果复盘接回网站。`
- 团队卡片只展示真实成员的姓名、角色、专长与头像；无真实团队资料时使用“能力模块”而非虚拟人物。
- 组件：`TeamGrid`、`TeamMemberCard`、`CapabilityCard`。

## 03. 工作原则
- `先明确要解决的问题，再选择渠道和功能。`
- `先做影响最大的页面与动作，不用无关功能拖慢上线。`
- `用可复核的数据讨论结果，不用漂亮但无法验证的指标。`
- 组件：`PrincipleList`、`ProcessSteps`。

## 04. CTA
- 文案：`如果你需要的是能协作、能交付、也能复盘的团队，欢迎聊聊。`
- 组件：`LogoWall`、`CertificationList`、`InlineCTA`、`SiteFooter`。

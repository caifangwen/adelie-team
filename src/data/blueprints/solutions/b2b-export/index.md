# B2B 外贸解决方案

## 01. Hero
- 标题：`把海外客户的搜索，变成更高质量的销售询盘。`
- 正文：`面对产品复杂、决策链长的 B2B 生意，网站的任务不是展示所有资料，而是先建立理解与信任，再让合适的买家愿意联系。`
- 按钮：`获取 B2B 获客方案`。
- 组件：`SiteHeader`、`SolutionHero`、`PrimaryButton`。

## 02. 典型障碍
- `产品参数很多，客户仍无法快速判断你是否适合。`
- `销售资料分散在 PDF、邮件和业务员脑中。`
- `询盘表单简单，销售团队难以判断优先级。`
- 组件：`PainPointGrid`、`PainPointCard`。

## 03. 推荐页面与服务
- `获客型 WordPress 官网`：`用清晰的价值主张、能力证明和联系路径承接品牌流量。`
- `产品与行业页`：`按买家问题组织内容，而非只复制产品目录。`
- `案例与认证页`：`用交付过程、测试、客户结果和资质降低决策风险。`
- `SEO + 搜索广告`：`覆盖“产品 + 应用 + 市场”等高意向搜索。`
- 组件：`SolutionStack`、`ServiceCard`。

## 04. 询盘路径
- `Google 搜索 / 广告` → `行业或产品页` → `能力证明、规格与案例` → `报价 / 样品 / 技术咨询表单` → `CRM 或销售跟进`。
- 表单提示：`建议增加产品、预计采购量、目标市场和项目时间字段，减少低质量往返。`
- 组件：`ConversionFlow`、`FlowStep`、`QualifiedLeadForm`。

## 05. CTA
- 标题：`让网站先帮销售团队完成第一轮沟通。`
- 按钮：`申请 B2B 网站诊断`。
- 组件：`CaseStudyCard`、`LeadForm`、`SiteFooter`。

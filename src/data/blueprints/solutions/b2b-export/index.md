## 02. 典型障碍
> 多数 B2B 网站的问题不是“不够漂亮”，而是没帮买家完成判断。
- `产品参数很多，客户仍无法快速判断你是否适合。`
- `销售资料分散在 PDF、邮件和业务员脑中。`
- `询盘表单简单，销售团队难以判断优先级。`
- 组件：`PainPointGrid`、`PainPointCard`。

## 03. 适用客户与业务场景
> 适合产品复杂、需要技术沟通或由多人共同决策的出海企业。
- `工业制造与设备企业`：`产品规格、应用条件和交付能力需要被海外采购与工程人员快速理解。`
- `OEM / ODM 供应商`：`需要说明定制边界、起订量、打样流程和质量控制。`
- `多市场出口企业`：`不同地区使用不同术语、认证和销售资料，需要统一内容底座。`
- `经销商与项目型业务`：`既要获得终端需求，也要筛选有价值的渠道与项目机会。`

## 04. 推荐页面与服务
> 每个页面都服务于同一个目标：让合适的买家愿意发起询盘。
- `获客型 WordPress 官网`：`用清晰的价值主张、能力证明和联系路径承接品牌流量。`
- `产品与行业页`：`按买家问题组织内容，而非只复制产品目录。`
- `案例与认证页`：`用交付过程、测试、客户结果和资质降低决策风险。`
- `SEO + 搜索广告`：`覆盖“产品 + 应用 + 市场”等高意向搜索。`
- 组件：`SolutionStack`、`ServiceCard`。

## 05. 页面与功能清单
> 首期只建设影响理解、验证和询盘的页面，不复制整套纸质目录。
- `核心页面`：`首页、能力页、重点产品页、行业或应用页、案例页、关于页与联系页。`
- `证明材料`：`认证、测试能力、质量流程、交付市场、客户类型和可公开案例。`
- `询盘功能`：`按报价、样品和技术咨询设置入口，并记录产品、地区与来源。`
- `增长基础`：`关键词映射、技术 SEO、分析事件、广告落地页和 CRM 字段对接。`

## 06. 询盘路径
- `Google 搜索 / 广告` → `行业或产品页` → `能力证明、规格与案例` → `报价 / 样品 / 技术咨询表单` → `CRM 或销售跟进`。
- 表单提示：`建议增加产品、预计采购量、目标市场和项目时间字段，减少低质量往返。`
- 图片：`https://images.unsplash.com/photo-1454165804606-c3d57bc86b40`
- 组件：`ConversionFlow`、`FlowStep`、`QualifiedLeadForm`。

## 07. 实施路径与衡量指标
> 先跑通一个重点市场和产品线，再复制已经验证的结构。
- `诊断与规划`：`访谈销售和产品团队，盘点搜索需求、现有内容、案例与询盘质量。`
- `内容与建设`：`先完成核心产品、行业、案例和联系路径，再补长尾内容。`
- `上线与验证`：`检查索引、表单、来源追踪和销售接收流程，避免有流量却丢线索。`
- `持续优化`：`按有效询盘率、重点页面进入率、表单完成率和销售反馈调整内容。`

## 11. 常见问题 FAQ
- `B2B 网站和普通展示型官网有什么区别？`：`展示型官网以公司介绍为中心；B2B 获客站围绕“建立信任 → 筛选客户 → 提交询盘”设计，每个页面都服务于让合适的买家发起咨询。`
- `网站上线后多久能看到询盘？`：`配合搜索广告通常几周内能拿到第一批数据；SEO 一般需要 3–6 个月积累。关键是先上线可追踪的询盘路径，再逐步放大流量。`
- `已经有老网站，应该改版还是新建？`：`先看数据再决定：有排名和外链的页面保留并优化，结构混乱、无法追踪的部分重建，避免把既有的搜索资产清零。`
- `询盘少，是流量问题还是网站问题？`：`两者要分开诊断：看流量来源和关键词意图判断流量质量，看访问路径和表单完成率判断网站问题，再决定预算投向。`

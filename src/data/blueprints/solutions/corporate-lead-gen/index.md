# 企业官网 / 获客站解决方案

## 01. Hero
- 标题：`别让官网只在客户已经认识你时才有用。`
- 正文：`一个有效的企业网站，应该说清价值、承接搜索、建立信任，并让销售线索可以被追踪和跟进。`
- 按钮：`获取官网诊断`。
- 组件：`SiteHeader`、`SolutionHero`、`PrimaryButton`。

## 02. 典型障碍
- `首页写了很多“关于我们”，客户仍不知道你为谁解决什么问题。`
- `服务与案例信息不完整，销售只能反复通过邮件补充材料。`
- `表单提交后没有事件追踪，无法知道哪些渠道带来线索。`
- 组件：`PainPointGrid`、`PainPointCard`。

## 03. 推荐页面与服务
- `首页与服务页`：`先回答客户“你是否适合我”。`
- `案例与证据页`：`用过程、结果、资质和客户评价降低不确定性。`
- `内容中心`：`覆盖高意向搜索问题，让官网持续累积流量。`
- `表单与数据追踪`：`让每一个咨询都有来源和后续动作。`
- 组件：`SolutionStack`、`ServiceCard`。

## 04. 获客路径
- `品牌搜索 / 内容搜索 / 广告` → `服务页或文章` → `案例、FAQ、证明材料` → `预约或咨询表单` → `销售跟进`。
- 组件：`ConversionFlow`、`FlowStep`。

## 05. CTA
- 标题：`看一看你的网站，到底有没有在帮业务获客。`
- 按钮：`申请免费诊断`。
- 组件：`CaseStudyCard`、`LeadForm`、`SiteFooter`。

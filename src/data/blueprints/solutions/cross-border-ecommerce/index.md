# 跨境电商解决方案

## 01. Hero
- 标题：`从一个可运营的商店，走向多个可增长的市场。`
- 正文：`跨境增长不是简单翻译页面。市场、货币、支付、物流、商品和投放数据需要在一套能执行的架构里协同。`
- 按钮：`规划跨境商店方案`。
- 组件：`SiteHeader`、`SolutionHero`、`PrimaryButton`。

## 02. 典型障碍
- `不同市场的价格、配送承诺和内容没有区分。`
- `商品数量增长后，用户找不到适合自己的产品。`
- `广告数据和订单数据无法对齐，难以判断市场价值。`
- 组件：`PainPointGrid`、`PainPointCard`。

## 03. 推荐方案
- `Shopify Markets 架构`：`先明确首发市场，再设置货币、语言、价格和配送规则。`
- `商品与集合策略`：`用用途、场景和需求帮助用户筛选，而不仅按品类堆叠。`
- `Google Ads / Shopping`：`根据商品利润、市场成熟度和数据基础逐步测试。`
- `SEO 内容与技术基础`：`让国家/语言版本具备清晰的索引和内容策略。`
- 组件：`SolutionStack`、`ServiceCard`。

## 04. 运营闭环
- `商品与库存` → `市场配置` → `商店与落地页` → `广告 / SEO 流量` → `订单与归因` → `转化优化`。
- 组件：`GrowthFunnel`、`FunnelStage`。

## 05. CTA
- 标题：`先确定最值得进入的市场，再增加复杂度。`
- 按钮：`申请跨境增长诊断`。
- 组件：`CaseStudyCard`、`LeadForm`、`SiteFooter`。

# DTC 品牌出海解决方案

## 01. Hero
- 标题：`让品牌故事，最终落到一笔订单上。`
- 正文：`DTC 独立站既要建立偏好，也要减少购买犹豫。我们用 Shopify、落地页和增长内容，把两件事放到同一条路径上。`
- 按钮：`获取 DTC 商店方案`。
- 组件：`SiteHeader`、`SolutionHero`、`PrimaryButton`。

## 02. 典型障碍
- `广告把人带来，商品页却没能回答“为什么是它”。`
- `首页有品牌感，但移动端购买步骤太长。`
- `爆品与长尾产品没有清晰的内容和流量策略。`
- 组件：`PainPointGrid`、`PainPointCard`。

## 03. 推荐页面与服务
- `品牌型 Shopify 商店`：`用统一视觉、价值主张和导航建立品牌记忆。`
- `高转化商品页`：`利益点、证据、使用场景、FAQ 和配送承诺按决策顺序呈现。`
- `广告落地页`：`针对单一人群与单一主张，减少页面干扰。`
- `SEO 内容`：`回答成分、对比、使用方法与问题型搜索。`
- 组件：`SolutionStack`、`ServiceCard`。

## 04. 成交与复购路径
- `社媒 / Google Ads` → `产品或 Campaign 页` → `加购` → `结账` → `订单确认` → `邮件 / 短信复购`。
- 关键指标：`商品页转化率、加购率、结账完成率、首购 CPA、复购率。`
- 组件：`ConversionFlow`、`FlowStep`、`KpiCard`。

## 05. CTA
- 标题：`先找出用户在哪一步放弃购买。`
- 按钮：`申请商店转化诊断`。
- 组件：`CaseStudyCard`、`LeadForm`、`SiteFooter`。

# 整站增长方案

## 01. Hero
- 眉题：`WEBSITE + SEO + GOOGLE ADS`
- 标题：`让网站、流量和转化说同一种语言。`
- 正文：`当建站、SEO 和广告由不同团队分别推进，常常会得到一个漂亮的网站和一份无法转化的流量报表。我们把它们放进同一份增长计划。`
- 按钮：`规划我的增长方案`。
- 图片：`https://images.unsplash.com/photo-1553877522-43269d4ea984`
- 组件：`SiteHeader`、`ServiceHero`、`PrimaryButton`。

## 02. 一条完整增长链路
- `找到机会`：`明确市场、买家、产品优势与竞争位置。`
- `承接需求`：`用网站、服务页、产品页或落地页把价值说清楚。`
- `获取访问`：`用 SEO 覆盖持续需求，用 Ads 验证和放大高意向需求。`
- `转成业务`：`追踪询盘、订单和线索质量，调整页面与投放。`
- 组件：`GrowthFunnel`、`FunnelStage`。

## 03. 适合谁
- `新市场启动`：`没有成熟海外网站，需要先建立可信的销售阵地。`
- `网站改版后增长停滞`：`需要把现有流量转成更有效的线索或订单。`
- `广告成本持续上升`：`需要同时改进落地页、追踪和自然流量结构。`
- 组件：`UseCaseGrid`、`UseCaseCard`。

## 04. 合作机制
- `每月一个明确目标`：`如关键页面上线、首批内容发布、有效线索成本下降。`
- `同一份数据口径`：`网站、自然流量与广告转化使用一致的定义。`
- `固定复盘节奏`：`每月看结果与下一步，不只汇报执行量。`
- 组件：`OperatingModelGrid`、`KpiDashboardPreview`。

## 05. 综合案例 + CTA
- 案例结构：`旧站问题 → 新站与内容策略 → 广告测试 → 流量/询盘/订单变化`。
- CTA：`告诉我们你的市场、现有站点和目标，获取优先级建议。`
- 组件：`CaseStudyCard`、`MetricTimeline`、`QualifiedLeadForm`、`SiteFooter`。

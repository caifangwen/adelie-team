# WordPress 案例

## 01. Hero
- 标题：`复杂业务，也可以被讲得清楚又有说服力。`
- 正文：`查看我们如何把企业能力、产品资料与客户证据整理成能带来询盘的 WordPress 网站。`
- 组件：`SiteHeader`、`ArchiveHero`。

## 02. 筛选与列表
- 筛选：`全部`、`工业制造`、`专业服务`、`新能源`、`企业官网`、`B2B 获客站`。
- 卡片示例：`NovaTech｜工业制造｜官网重构 + SEO 基础｜询盘量 +68%`。
- 组件：`FilterBar`、`FilterChip`、`CaseStudyGrid`、`CaseStudyCard`、`MetricBadge`。

## 03. CTA
- 文案：`先把最影响询盘的页面找出来，再决定是否改版。`
- 组件：`InlineCTA`、`LeadForm`、`SiteFooter`。

# 案例详情：ClearForm B2B 关键词重构

## 01. Hero

- 图片：`https://images.unsplash.com/photo-1460925895917-afdab827c52f`
- 标签：`B2B｜内容增长｜英文市场｜关键词策略`
- 标题：`从泛流量转向真正推动询盘的行业与应用词。`
- 成果：`高意向页面覆盖扩大`、`询盘质量提升`。
- 注：示例客户与数据仅用于内容结构演示，发布时替换为授权案例。
- 组件：`SiteHeader`、`CaseHero`、`MetricBadge`、`Notice`。

## 02. 客户背景与挑战

- 正文：`ClearForm 的内容带来稳定访问，但大量页面覆盖的是低商业意图主题，销售团队难以从中识别合格线索。`
- 组件：`TextMediaSplit`、`ChallengeList`。

## 03. 我们的做法

- `重建关键词地图`：`将行业、应用、规格和采购问题分配给不同页面。`
- `收敛内容优先级`：`优先完成与产品能力和销售线索最相关的主题。`
- `优化内部链接`：`让高意向内容更容易进入产品页与咨询入口。`
- 组件：`ApproachSteps`、`KeywordMapPreview`。

## 04. 结果与证据

- 图表标题：`内容调整后：高意向页面覆盖与询盘来源变化`。
- 说明：`按页面意图和来源记录变化，不将单一指标作为承诺。`
- 组件：`BeforeAfterChart`、`MetricGrid`、`EvidenceNote`。

## 05. CTA

- 文案：`找出正在争抢流量、却没有推动业务的内容。`
- 组件：`RelatedCaseList`、`LeadForm`、`SiteFooter`。

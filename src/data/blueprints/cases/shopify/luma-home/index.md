# 案例详情：Luma Home Shopify 转化优化

## 01. Hero
- 图片：`https://images.unsplash.com/photo-1472851294608-062f824d29cc`
- 标签：`家居生活｜Shopify 改版｜CRO`
- 标题：`让移动端用户更快理解产品，也更容易完成购买。`
- 成果：`移动端转化率 +32%`、`结账前流失下降`。
- 注：示例客户与数据仅用于内容结构演示，发布时替换为授权案例。
- 组件：`SiteHeader`、`CaseHero`、`MetricBadge`、`Notice`。

## 02. 客户背景与挑战
- 正文：`Luma Home 的广告流量稳定，但商品页利益点、评价、配送信息与移动端加购入口分散，用户需要反复滚动寻找关键答案。`
- 组件：`TextMediaSplit`、`ChallengeList`。

## 03. 我们的做法
- `重新排序商品页信息`：`先讲核心利益，再给场景、证据、规格和 FAQ。`
- `优化移动端购买入口`：`强化加购区、配送承诺与评价跳转。`
- `统一 Campaign 落地页`：`让广告主张与页面首屏一致。`
- 组件：`ApproachSteps`、`BeforeAfterMockup`。

## 04. 结果与证据
- 图表标题：`改版前后：移动端转化、加购与结账完成率`。
- 说明：`统一使用同一市场、同一归因窗口的对比数据。`
- 组件：`BeforeAfterChart`、`MetricGrid`、`EvidenceNote`。

## 05. CTA
- 文案：`先找出用户在商品页犹豫的原因。`
- 组件：`RelatedCaseList`、`LeadForm`、`SiteFooter`。

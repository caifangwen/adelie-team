# 案例详情：Northline Outdoor 多市场商店

- 图片：`https://images.unsplash.com/photo-1551698618-1dfe5d97d256`

- 注：示例客户与数据仅用于内容结构演示，发布时替换为授权案例。

## 02. 客户背景与挑战

- 正文：`Northline Outdoor 同时服务多个市场，但库存、币种和商品卖点在广告与商店页面中呈现不一致。`
- 组件：`TextMediaSplit`、`ChallengeList`。

## 03. 我们的做法

- `统一多市场商品信息`：`为主要市场梳理价格、配送与规格表达。`
- `重构集合页与商品页`：`先帮助用户缩小选择，再回答购买疑问。`
- `匹配广告落地页`：`让不同产品线的广告进入对应商品或集合页。`
- 组件：`ApproachSteps`、`BeforeAfterMockup`。

- 图表标题：`优化后：市场页面路径与广告落地页匹配度`。
- 说明：`展示已上线市场与产品范围，不将相关性写成因果承诺。`
- 组件：`BeforeAfterChart`、`MetricGrid`、`EvidenceNote`。

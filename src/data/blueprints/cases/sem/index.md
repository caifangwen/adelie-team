# SEM 投放案例

## 01. Hero
- 标题：`广告表现好不好，不能只看点击。`
- 正文：`查看我们如何通过追踪、账户结构、搜索词与落地页优化，改善获客成本与回报。`
- 组件：`SiteHeader`、`ArchiveHero`。

## 02. 筛选与列表
- 筛选：`全部`、`B2B 询盘`、`DTC 电商`、`Search`、`Shopping`、`PMax`。
- 卡片示例：`Arden Tools｜B2B｜Google Search 重构｜有效线索成本 -24%`。
- 组件：`FilterBar`、`FilterChip`、`CaseStudyGrid`、`CaseStudyCard`、`MetricBadge`。

## 03. CTA
- 文案：`把账户交给数据审一遍，先找出最明显的浪费。`
- 组件：`InlineCTA`、`LeadForm`、`SiteFooter`。
